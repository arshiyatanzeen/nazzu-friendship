NAZZU.EXE × ARSHI.EXE — FRIENDSHIP INCIDENT REPORT

A one-file, mobile-friendly interactive website for a strictly platonic 2-month friendship anniversary.

PREVIEW
1. Extract the ZIP.
2. Open index.html in your browser, or use VS Code + Live Server.
3. Click around: start the case file, release chaos, choose a fate, take the quiz, and unlock the final message using NAZZU.

PERSONALISE IT
Open index.html in a text editor and change any copy to include real inside jokes or shared memories. The sample timeline is intentionally generic because no specific shared memories were provided.

PUBLISH FREE WITH GITHUB PAGES
1. Sign in/create an account at https://github.com/
2. Create a public repository, e.g. nazzu-friendship.
3. Upload index.html to the repository root and commit.
4. Open Settings → Pages.
5. Select Deploy from a branch, choose main and /(root), then Save.
6. Wait for GitHub to publish it. Copy the actual URL shown in Settings → Pages and send it to Nazzu.
Do not guess the public URL; copy the one GitHub provides.

PRIVACY
This is a static page. It does not collect or send quiz answers or personal data. Anyone with the public link can view it. Avoid adding private screenshots or sensitive information.
